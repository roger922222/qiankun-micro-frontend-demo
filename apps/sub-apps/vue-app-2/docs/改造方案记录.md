# Vue App 2 (文件管理应用) 改造方案记录

## 改造目标
参考 vue-app-1 的成功优化方案，对 vue-app-2 进行相同的改造，解决 qiankun 微前端环境下的样式冲突和错误。

## 主要改造内容

### 1. 样式处理优化
- **移除 scoped 样式**：避免与 qiankun 样式沙箱冲突
- **使用命名空间隔离**：采用 `.vue-file-management` 作为根命名空间
- **全局样式导入**：在 main.ts 中全局导入样式，避免组件级动态样式注入
- **样式优先级**：使用 `!important` 确保样式在微前端环境下正确显示

### 2. qiankun 兼容性优化
- **配置 vite-plugin-legacy-qiankun 插件**：解决 ES 模块兼容性问题
- **优化 Vite 配置**：
  - 关闭 CSS 代码分割 (`cssCodeSplit: false`)
  - 配置 HMR 减少样式冲突
  - 添加样式修复工具
- **错误监控**：集成样式错误监控和自动恢复机制

### 3. 路由系统优化
- **创建完整路由配置**：`src/router/index.ts`
- **实现路由懒加载**：提升首次加载速度和切换性能
- **添加路由守卫**：`src/router/guards.ts` 处理路由切换逻辑
- **性能监控**：记录路由切换性能数据

### 4. 布局和 UI 优化
- **实现侧边栏菜单布局**：包含文件管理、上传、预览、设置等功能
- **添加收起/展开功能**：优化空间利用
- **优化样式主题**：统一的设计风格和交互效果

## 具体实施步骤

### 步骤 1: 基础配置
1. 安装 `vite-plugin-legacy-qiankun` 插件
2. 创建 `vite.config.ts` 配置文件
3. 配置端口为 3007，避免冲突

### 步骤 2: 目录结构创建
```
src/
├── router/           # 路由配置
├── views/            # 页面组件
├── components/       # 通用组件
│   └── Layout/       # 布局组件
├── store/            # 状态管理 (Pinia)
├── utils/            # 工具函数
└── styles/           # 样式文件
```

### 步骤 3: 路由系统实现
- 创建路由配置文件，包含文件管理相关页面
- 实现路由懒加载和性能监控
- 添加路由守卫处理切换逻辑

### 步骤 4: 样式系统优化
- 创建全局样式文件 `styles/index.css`
- 使用命名空间 `.vue-file-management` 隔离样式
- 集成 qiankun 样式修复工具

### 步骤 5: 主应用入口优化
- 重构 `main.ts` 使用 vite-plugin-legacy-qiankun
- 配置微前端生命周期函数
- 添加样式错误处理和监控

### 步骤 6: 布局组件实现
- 创建 Header、Sidebar、Footer 布局组件
- 实现响应式设计和交互功能
- 集成 Ant Design Vue 组件库

### 步骤 7: 状态管理
- 使用 Pinia 创建文件管理状态存储
- 实现文件和文件夹的 CRUD 操作
- 添加搜索、选择等功能
