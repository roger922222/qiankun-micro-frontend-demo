# Redis缓存配置

## 环境变量配置

可以通过以下环境变量配置Redis连接：

```bash
# Redis连接配置
REDIS_HOST=localhost        # Redis服务器地址
REDIS_PORT=6379            # Redis服务器端口
REDIS_PASSWORD=            # Redis密码（可选）
REDIS_DB=0                 # Redis数据库编号

# 缓存TTL配置（秒）
CACHE_TTL_USERS=300        # 用户列表缓存时间（5分钟）
CACHE_TTL_USER_DETAIL=600  # 用户详情缓存时间（10分钟）
CACHE_TTL_ROLES=1800       # 角色缓存时间（30分钟）
```

## 缓存策略

### 1. 用户数据缓存
- **用户列表**: 缓存5分钟，支持分页、搜索、过滤参数
- **用户详情**: 缓存10分钟，按用户ID缓存
- **清理策略**: 创建、更新、删除用户时清理相关缓存

### 2. 缓存键命名规范
```
cache:users:list:{params}     # 用户列表缓存
cache:users:{userId}          # 用户详情缓存
cache:roles:list              # 角色列表缓存
cache:permissions:list        # 权限列表缓存
```

### 3. 缓存命中率优化
- 合理设置TTL时间，平衡性能与数据实时性
- 使用缓存装饰器简化缓存逻辑
- 实现缓存预热机制

## 性能监控

### 缓存指标
- 缓存命中率
- 平均响应时间
- 缓存清理频率
- Redis内存使用情况

### 监控端点
```
GET /health          # 基础健康检查
GET /health/redis    # Redis连接状态
```

## 故障处理

### Redis连接失败
- 自动降级：缓存功能不可用，直接访问数据库
- 错误日志：记录Redis连接错误
- 健康检查：定期检查Redis连接状态

### 缓存穿透保护
- 空值缓存：对查询结果为空的数据也进行缓存
- 布隆过滤器：防止恶意查询不存在的数据
- 限流保护：防止缓存失效时的并发查询

## 最佳实践

### 1. 缓存粒度
- 按业务模块划分缓存
- 避免缓存过大对象
- 使用合适的缓存键

### 2. 缓存更新
- 采用Write-Through策略
- 实现缓存失效机制
- 避免缓存雪崩

### 3. 内存管理
- 设置合理的TTL时间
- 定期清理过期缓存
- 监控内存使用情况
