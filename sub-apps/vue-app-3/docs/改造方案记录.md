# Vue App 3 (系统监控应用) 改造方案记录

## 改造目标
参考 vue-app-1 的成功优化方案，对 vue-app-3 进行相同的改造，解决 qiankun 微前端环境下的样式冲突和错误。

## 主要改造内容

### 1. 样式处理优化
- **移除 scoped 样式**：避免与 qiankun 样式沙箱冲突
- **使用命名空间隔离**：采用 `.vue-system-monitor` 作为根命名空间
- **全局样式导入**：在 main.ts 中全局导入样式，避免组件级动态样式注入
- **样式优先级**：使用 `!important` 确保样式在微前端环境下正确显示

### 2. qiankun 兼容性优化
- **配置 vite-plugin-legacy-qiankun 插件**：解决 ES 模块兼容性问题
- **优化 Vite 配置**：
  - 关闭 CSS 代码分割 (`cssCodeSplit: false`)
  - 配置 HMR 减少样式冲突
  - 添加样式修复工具
- **错误监控**：集成样式错误监控和自动恢复机制

### 3. 路由系统优化
- **创建完整路由配置**：`src/router/index.ts`
- **实现路由懒加载**：提升首次加载速度和切换性能
- **添加路由守卫**：`src/router/guards.ts` 处理路由切换逻辑
- **性能监控**：记录路由切换性能数据

### 4. 布局和 UI 优化
- **实现侧边栏菜单布局**：包含系统概览、性能监控、日志查看、告警管理、服务监控等功能
- **添加收起/展开功能**：优化空间利用
- **优化样式主题**：统一的设计风格和交互效果
- **实时数据更新**：模拟系统监控数据的实时更新

1. 安装 `vite-plugin-legacy-qiankun` 插件

├── components/       # 通用组件
│   └── Layout/       # 布局组件
