# Vue-App-1 功能完善技术设计文档

## 1. 项目概述
### 1.1 项目背景
vue-app-1 是一个基于 Vue 3 + TypeScript + Ant Design Vue 的微前端消息中心应用，当前已实现基础的消息管理和通知功能，但缺少完整的路由系统、消息推送管理页面，同时存在页面排版问题和状态管理优化需求。

### 1.2 核心问题
1. 路由配置文件缺失，导致页面导航异常
2. 缺少综合性的消息推送管理页面
3. 页面排版存在布局和样式问题
4. 状态管理结构需要扩展和优化

### 1.3 解决方案概述
通过创建完整的路由系统、开发消息推送管理页面、修复样式问题、优化状态管理结构，完善 vue-app-1 的功能体系，确保与微前端架构的兼容性。

## 4. 技术架构

### 4.1 整体架构
```
vue-app-1/
├── src/
│   ├── router/           # 路由配置
│   │   └── index.ts     # 主路由文件
│   ├── views/           # 页面组件
│   │   ├── MessageCenter.vue    # 消息列表页面
│   │   ├── Notifications.vue    # 通知中心页面
│   │   └── MessagePush.vue      # 消息推送页面（新增）
│   ├── components/      # 组件库
│   │   └── Layout/      # 布局组件
│   ├── store/           # 状态管理
│   │   ├── index.ts     # 主store文件
│   │   └── modules/     # 状态模块
│   └── styles/          # 样式文件
```

### 4.2 核心组件
**前端组件**
- MessagePush.vue: 消息推送管理页面，包含推送设置、历史记录、手动发送功能
- 路由系统: 基于 Vue Router 4 的单页面应用路由管理
- 优化后的布局组件: 修复排版问题的 Layout 组件

### 4.3 技术选型
**前端技术栈**
- Vue 3.3.4 + Composition API
- TypeScript 5.1.6
- Vue Router 4.2.4 (路由管理)
- Vuex 4.1.0 (状态管理)
- Ant Design Vue 4.0.0 (UI组件库)
- Vite 4.4.5 (构建工具)

## 5. 核心设计

### 5.1 数据模型和关系
**推送管理模块状态结构**
```typescript
interface PushState {
  pushSettings: PushSetting[];     // 推送设置列表
  pushHistory: PushRecord[];       // 推送历史记录
  pushStats: PushStatistics;       // 推送统计信息
  activePushes: ActivePush[];      // 活跃推送任务
}

interface PushSetting {
  id: string;
  name: string;
  type: 'scheduled' | 'trigger' | 'manual';
  conditions: PushCondition[];
  channels: PushChannel[];
  enabled: boolean;
  createdAt: string;
  updatedAt: string;
}

interface PushRecord {
  id: string;
  title: string;
  content: string;
  targetType: 'all' | 'group' | 'user';
  targetIds: string[];
  status: 'sent' | 'failed' | 'pending';
  sentAt: string;
}
```

**用户偏好模块状态结构**
```typescript
interface PreferencesState {
  notifications: NotificationPreferences;
  display: DisplayPreferences;
  privacy: PrivacyPreferences;
}

interface NotificationPreferences {
  enablePush: boolean;
  enableEmail: boolean;
  enableSMS: boolean;
  quietHours: { start: string; end: string };
}
```

### 5.2 前端设计
| 组件名 | 路径 | 描述 | 参数 |
|--------|------|------|------|
| MessagePush | /src/views/MessagePush.vue | 消息推送管理页面 | 无 |
| PushSettings | /src/components/Push/PushSettings.vue | 推送设置组件 | settings: PushSetting[] |
| PushHistory | /src/components/Push/PushHistory.vue | 推送历史组件 | history: PushRecord[] |

```

```

### 5.3 服务端设计
本项目为前端应用，无服务端API设计需求。状态管理通过 Vuex 和 localStorage 实现数据持久化。
