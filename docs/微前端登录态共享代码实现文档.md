## 🔗 统一导入机制

### 共享Hook架构
- **集中管理**: 所有认证逻辑集中在共享层
- **统一接口**: 所有子应用使用相同的API接口
- **类型安全**: 完整的TypeScript类型定义
- **自动同步**: 修改共享层自动同步到所有应用

### 子应用引用方式
```typescript
// React子应用 - 本地引用文件
import { useAuth } from './hooks/useAuth';

// Vue子应用 - 本地引用文件  
import { useAuth } from './composables/useAuth';

// 实际都是从共享层导入，保持代码一致性
```

## 🎯 技术架构特点

### 双方案支持
- **同域方案**: 基于Cookie共享，适用于同一顶级域名
- **跨域方案**: 基于Token共享，适用于不同域名

### 实时同步机制
- **BroadcastChannel**: 现代浏览器支持的多上下文通信
- **Storage事件**: 基于localStorage的跨标签页同步
- **事件总线**: 应用内的事件发布订阅机制

### 安全保障
- **Token加密**: 基于主机名的异或加密
- **CSRF防护**: 请求级别的Token验证
- **过期检查**: 自动Token过期验证
- **权限控制**: 细粒度的权限验证机制

### 用户体验
- **无感刷新**: 后台自动Token刷新
- **统一登录**: 单点登录体验
- **错误恢复**: 智能的错误处理和重试
- **状态同步**: 多应用间状态实时同步

## 🔧 使用方法

### 基础配置
```typescript
// 主应用中初始化
import { AuthBridge } from '@shared/communication';

const authBridge = AuthBridge.getInstance();
authBridge.initialize();
```

### React子应用使用
```typescript
import { useAuth } from './hooks/useAuth';

function MyComponent() {
  const { token, isAuthenticated, login, logout } = useAuth('react-app-1');
  
  if (!isAuthenticated) {
    return <LoginForm onLogin={login} />;
  }
  
  return <Dashboard onLogout={logout} />;
}
```

### Vue子应用使用
```typescript
import { useAuth } from '@/composables/useAuth';

export default {
  setup() {
    const { token, isAuthenticated, login, logout } = useAuth('vue-app-1');
    
    return {
      isAuthenticated,
      login,
      logout
    };
  }
};
```

## 🔒 安全建议

1. **HTTPS部署**: 生产环境必须使用HTTPS
2. **Cookie配置**: 正确设置Secure、HttpOnly、SameSite属性
3. **Token有效期**: 设置合理的Token过期时间
4. **刷新机制**: 启用自动Token刷新功能
5. **权限验证**: 所有敏感操作都需要权限验证
6. **监控告警**: 配置认证异常监控和告警
