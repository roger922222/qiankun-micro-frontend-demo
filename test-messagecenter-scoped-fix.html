🔧 MessageCenter Scoped 样式修复测试

测试 qiankun 微前端环境下 MessageCenter.vue 组件的 scoped 样式冲突修复效果

测试时间: 状态: 准备中

📋 测试概述

问题描述: MessageCenter.vue 组件使用 scoped 样式时，在 qiankun 微前端环境下触发样式沙箱冲突，导致 "Cannot read properties of null (reading 'contains')" 错误。

修复方案: 移除所有 Vue 组件中的 scoped 属性，使用命名空间前缀实现样式隔离。

测试目标: 验证移除 scoped 后样式错误是否消失，样式隔离是否正常工作。

🔄 修复前后对比

修复前 (有问题的配置):

<style scoped>
.message-center {
  padding: 16px;
  min-height: calc(100vh - 200px);
}
</style>

问题: scoped 属性会导致 Vue 动态注入样式，触发 qiankun 样式沙箱的 DOM 操作拦截，造成 null 引用错误。

修复后 (正确的配置):

<style>
.vue-message-center .message-center {
  padding: 16px;
  min-height: calc(100vh - 200px);
}
</style>

优势: 使用命名空间前缀 (.vue-message-center) 实现样式隔离，避免动态样式注入，与 qiankun 沙箱兼容。
